# Terraform Associate (004) — Complete Study Guide & Exam Preparation

A clean, structured, and exam‑aligned study repository for the **HashiCorp Terraform Associate (004)** certification.

This repo is designed to help both beginners and experienced engineers prepare efficiently with:

- Clear explanations of every exam topic  
- Real Terraform examples  
- Diagrams for visual learning  
- Exam tips and common pitfalls  
- 100+ practice questions  
- A 30‑day study plan  
- Topic‑by‑topic notes aligned with the official exam blueprint

## 📘 Exam Blueprint (Terraform Associate 004)

This repo covers all domains:

1. Understand Infrastructure as Code (IaC) concepts  
2. Understand Terraform’s purpose  
3. Use Terraform CLI  
4. Interact with Terraform modules  
5. Navigate Terraform workflow  
6. Implement and maintain state  
7. Read, generate, and modify configurations  
8. Understand Terraform Cloud capabilities  

Each folder in this repo maps directly to these domains.
